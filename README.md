# Non-Linear Model Predictive Control for Mecanum Ballbot

This repo contains code that implements Non-Linear Model Predictive Control for the robot described in [Modeling and Control of a Ballbot](https://www.research-collection.ethz.ch/entities/publication/9811b9ea-58db-4376-bea2-6ef02ac21043). Project was inspired during my time taking [ROB 311](https://github.com/michiganrobotics/rob311).

This project utilizes [Drake](https://drake.mit.edu/).

## Usage

```bash
bazel run //ballbot:ballbot_mpc_main
```
